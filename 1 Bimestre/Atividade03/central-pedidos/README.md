# Atividade 03 — Teste estrutural com JUnit

Projeto-base `central-pedidos` da Semana 06, com uma suíte JUnit 5 que exercita entidades, desconto, frete, risco, pagamento e os retornos do fechamento de pedido.

## Executar

```powershell
cd Atividade03\central-pedidos
mvn clean test
```

O JaCoCo gera o relatório em `target/site/jacoco/index.html`.
